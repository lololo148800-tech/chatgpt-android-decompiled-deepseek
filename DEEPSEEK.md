# Инструкция для анализа в DeepSeek

## Контекст проекта

Перед тобой не исходный Android Studio-проект, а декомпилированная версия приложения ChatGPT для Android. Основной результат находится в `decompiled/sources/` и `decompiled/resources/`. Оригинальные split APK находятся в `artifacts/apk/` и используются только для сверки.

## Правила анализа

Сначала прочитай `README.md`, затем `REPO_MAP.md` и `decompiled/resources/AndroidManifest.xml`. После этого определяй, относится ли найденный класс к коду приложения или к внешней библиотеке. Код приложения обычно находится под `com.openai`, а зависимости — под `androidx`, `kotlin`, `okhttp3`, `com.google`, `com.auth0`, `com.withpersona`, `io`, `livekit`, `coil` и другими namespace.

Не воспринимай декомпилированную Java-структуру как точную копию оригинального исходного проекта. Если встречаются имена вида `C1234A`, `AbstractC...`, `p000...` или похожие обфусцированные обозначения, считай их артефактами обфускации и декомпиляции. При сомнениях сообщай об уровне уверенности и указывай альтернативные интерпретации.

Каждое существенное утверждение подтверждай ссылкой на конкретный путь, класс и метод. Если вывод основан на манифесте, указывай XML-узел. Если код недоступен или восстановлен с ошибками, прямо отмечай это вместо реконструкции по догадке.

## Рекомендуемый формат ответа

```text
Краткий вывод:

Доказательства:
1. path/to/File.java — ClassName.methodName(...): что именно найдено.
2. path/to/AndroidManifest.xml — соответствующий компонент или permission.

Цепочка вызовов:
- Начальная точка → промежуточный класс → конечная операция.

Ограничения уверенности:
- Какие части подтверждены напрямую.
- Какие части зависят от декомпиляции или обфускации.

Что проверить дальше:
- Следующие файлы, классы или ресурсы.
```

## Полезные поисковые направления

Для навигации по проекту используй следующие группы:

| Вопрос | Где искать в первую очередь |
|---|---|
| Точки входа приложения | `decompiled/resources/AndroidManifest.xml`, `decompiled/sources/com/openai/` |
| Авторизация и регистрация | `decompiled/sources/com/openai/feature/onboarding/`, `decompiled/sources/com/auth0/` |
| Голосовые функции | `decompiled/sources/com/openai/feature/voice/`, `decompiled/sources/livekit/` |
| Сетевые операции | `decompiled/sources/com/openai/network/`, `decompiled/sources/okhttp3/` |
| Хранение состояния | `decompiled/sources/com/openai/`, `decompiled/sources/androidx/datastore/` |
| Платежи | `decompiled/sources/com/android/billingclient/`, `decompiled/sources/com/google/android/gms/` |
| Интерфейс | `decompiled/resources/res/layout/`, `decompiled/resources/res/values/`, пакеты `com/openai/feature/` |
| Разрешения и фоновые компоненты | `decompiled/resources/AndroidManifest.xml` |

## Готовые запросы

### Обзор архитектуры

```text
Построй карту архитектуры приложения по decompiled/sources/com/openai/. Найди основные модули, ViewModel, репозитории, сетевые клиенты и точки входа. Не включай сторонние библиотеки в основной граф. Для каждого узла укажи точный путь к файлу и оцени уверенность.
```

### Трассировка функции

```text
Проследи путь выполнения функции [название функции] от пользовательского действия до сетевого запроса или изменения состояния. Ищи связанные intent, ViewModel, use-case, repository и API-клиент. Приведи цепочку файлов, классов и методов. Не делай выводов о коде, которого нет в репозитории.
```

### Проверка разрешений

```text
Проанализируй permissions и компоненты в decompiled/resources/AndroidManifest.xml. Для каждого чувствительного разрешения найди места использования в decompiled/sources/com/openai/ и отдели подтвержденное использование от предположений.
```

### Поиск потенциальной проблемы

```text
Проведи статический анализ участка [путь или пакет]. Ищи ошибки обработки исключений, небезопасное хранение данных, неправильные проверки permission и возможные утечки ресурсов. Учитывай ограничения декомпиляции. Для каждого замечания укажи доказательства и уровень уверенности.
```
