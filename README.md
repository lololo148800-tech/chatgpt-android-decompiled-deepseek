# ChatGPT Android — декомпилированный APK

Этот репозиторий подготовлен из предоставленного XAPK-набора и организован так, чтобы исходное поведение приложения было удобно анализировать в DeepSeek и других моделях, работающих с GitHub-кодом.

> Важно: архив содержит не исходный проект Android Studio, а собранный набор APK-файлов. Каталог `decompiled/` — результат автоматической декомпиляции, поэтому этот код предназначен для чтения и анализа, но не гарантированно собирается обратно без ручного восстановления.

## Быстрый маршрут для DeepSeek

Для анализа репозитория рекомендуется начинать с этой последовательности:

1. Прочитать этот файл и `DEEPSEEK.md`.
2. Открыть `decompiled/resources/AndroidManifest.xml`, чтобы увидеть разрешения, компоненты и intent-фильтры.
3. Исследовать основной пакет `decompiled/sources/com/openai/`.
4. Для функциональных подсистем искать соответствующие каталоги внутри `decompiled/sources/com/openai/feature/`, `decompiled/sources/com/openai/core/`, `decompiled/sources/com/openai/network/` и `decompiled/sources/com/openai/infra/`.
5. Сверять Java-код с XML-ресурсами в `decompiled/resources/res/` и строками в `decompiled/resources/res/values/`.
6. Игнорировать или отдельно помечать пакеты сторонних библиотек (`androidx`, `kotlin`, `okhttp3`, `com/google`, `com/auth0`, `com/withpersona` и другие), если вопрос касается только логики приложения.

## Структура репозитория

| Путь | Назначение |
|---|---|
| `decompiled/sources/` | Декомпилированные Java-файлы. Это главный каталог для чтения логики приложения. |
| `decompiled/resources/` | Декомпилированный `AndroidManifest.xml`, XML-ресурсы, assets и другие ресурсы APK. |
| `artifacts/apk/` | Оригинальные APK-файлы из предоставленного набора, включая base APK и split-конфигурации. |
| `metadata/xapk-manifest.json` | Метаданные исходного XAPK-набора. |
| `metadata/SHA256SUMS` | SHA-256 контрольные суммы оригинальных файлов. |
| `metadata/DECOMPILATION.md` | Методика декомпиляции, ограничения и сведения о диагностике. |
| `metadata/jadx.log` | Журнал работы декомпилятора. |
| `REPO_MAP.md` | Краткая карта важных каталогов и направлений анализа. |
| `DEEPSEEK.md` | Готовая инструкция и шаблоны запросов для анализа репозитория в DeepSeek. |

## Ограничения

Декомпиляция не восстанавливает оригинальные имена локальных переменных, комментарии, систему сборки и исходные Kotlin-файлы. В результате могут присутствовать обфусцированные имена пакетов, синтетические классы, неполные конструкции и диагностические ошибки. Поэтому ответы модели следует проверять по нескольким связанным файлам и по манифесту.

Оригинальные APK сохранены для сопоставления, но они являются бинарными артефактами и не заменяют исходный код. Не запускайте их в рабочем окружении без отдельной проверки происхождения и безопасности.
